# 🛡️ CTF & Security Writeups

A collection of my personal writeups for cybersecurity challenges across **TryHackMe**, **Hack The Box**, **LetsDefend**, and various **CTF competitions**, covering both offensive and defensive security techniques.

## 📁 Structure

```

```

**Recon:** `nmap` · `gobuster` · `ffuf` · `whatweb`
